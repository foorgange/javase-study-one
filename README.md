# javase-study-one

Java SE 学习过程中的代码记录，包含基础语法、面向对象编程、字符串处理、数组操作等练习。

## 内容概览

- **面向对象基础**：`Animal.java`、`Cat.java`（继承示例）、`role.java`（角色类定义）
- **基础语法练习**：`数组.java`、`字符串.java`、`fang_fa.java`（方法）、`sout_scanner.java`（输入输出）
- **算法练习**：`sousuo.java`（搜索）、`类似结构体.java`（结构体模拟）
- **实验代码**：`src/shi_yan/Calculate.java`
- **学习笔记**：`git笔记.java`（Git 相关笔记，以 `.java` 后缀保存）

## 运行方式

所有源文件位于 `src/` 目录下，可通过 `javac` 编译、`java` 运行：

```bash
cd src
javac Animal.java
java Animal
```
